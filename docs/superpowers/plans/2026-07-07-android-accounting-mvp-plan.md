# Android Accounting MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first working Android version of YukiAccount from the approved design spec.

**Architecture:** Use a single native Android app module with Kotlin, Jetpack Compose, Room, and a thin repository/use-case layer. Keep financial rules in testable Kotlin services so statistics, account balance effects, recurring generation, and investment valuation can be verified without UI tests.

**Tech Stack:** Kotlin, Android Gradle Plugin, Jetpack Compose Material 3, Navigation Compose, Room, Kotlin Serialization, JUnit.

---

- Create Gradle project files: `settings.gradle.kts`, `build.gradle.kts`, `gradle.properties`, `local.properties`, `gradlew`, `gradlew.bat`, `gradle/wrapper/*`.

- Core rules: `domain/service`.
- UI: `ui`, `ui/screen`, `ui/component`, `ui/theme`.

## Task 2: Core Financial Rule Tests

**Files:**
- Create: `app/src/test/java/com/yukisora/yukiaccount/domain/service/LedgerCalculatorTest.kt`
- Create: `app/src/main/java/com/yukisora/yukiaccount/domain/service/LedgerCalculator.kt`
- Create: `app/src/main/java/com/yukisora/yukiaccount/domain/model/FinanceModels.kt`

- [ ] **Step 1: Write failing tests first**

Cover these behaviors:

- Asset-account expense reduces the account balance.
- Credit-card expense increases unpaid credit-card liability.
- Credit-card repayment reduces the source asset account and the card liability, but is excluded from consumption.
- Transfer is excluded from income and consumption.
- Investment buy reduces the source asset account, increases investment principal, and is excluded from consumption.
- Current net worth equals cash-like balances plus investment current value minus credit-card liability.
- Monthly real consumption includes expenses, subtracts refunds, and excludes transfer, repayment, investment buy, and valuation change.

- [ ] **Step 2: Verify tests fail**

Run: `.\gradlew.bat :app:testDebugUnitTest --tests "*LedgerCalculatorTest"`

Expected: fails because `LedgerCalculator` and domain models are missing.

- [ ] **Step 3: Implement minimal domain models and calculator**

Implement immutable Kotlin data classes and pure functions:

- `applyTransaction(accounts, investments, transaction)`
- `monthlyRealConsumption(transactions, month)`
- `netWorth(accounts, investments)`
- `investmentGainLoss(investment)`

- [ ] **Step 4: Verify tests pass**

Run: `.\gradlew.bat :app:testDebugUnitTest --tests "*LedgerCalculatorTest"`

Expected: tests pass.
